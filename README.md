# Battlefield Rate Card Builder

A single-page app for Battlefield Equipment Rentals sales reps to build customer-specific rate cards from the 2027 Zone A rental rates and publish them as PDFs.

Open the live app on GitHub Pages, or download `index.html` and open it in Edge or Chrome. No install needed.

- **Customer tab**: who the card is for and the rep's contact details.
- **Equipment tab**: include or remove sections and items, change prices, add custom items.
- **Pricing tab**: choose rate columns, apply a % adjustment, review changed rates.
- **Publish PDF**: opens the print window; choose "Save as PDF".

To update rates, use the ••• menu → **Update rates (admin)**, then replace `index.html` in this repository with the downloaded file.
